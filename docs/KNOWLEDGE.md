# 知识库贡献规范

0.8.0包含52张原创短卡：24张概念卡、28张方法卡。新增20卡覆盖拖延、沟通边界、完美主义、担忧、活动平衡、现实联系、间隔学习、提取练习、知识解释和睡眠。来源集中在公共医疗机构和学习研究者的原站资料，见[本次研究](../design/community-research.md)。数量不代表临床有效性。

当前可在 `app/growth.mjs` 添加卡和来源；已有 `K-001` 至 `K-052` 的ID不要重排或复用，旧记录依赖这些ID。概念卡至少包含title/tags/body/practice/limit/source；方法卡还必须有steps/followUp/stopWhen，注明reviewedAt。

提交前检查：

- 来源真实可访问，标题与URL对应；研究、官方教育和个人经验明确区分。
- 原创中文短文和例子；不把来源中的一般原则包装成经过研究验证的本软件疗法。
- 可试动作符合场景，有退出与调整条件；疲惫、拒绝建议、关系不安全和紧急风险时不能继续催任务。
- 不替用户诊断、不承诺解开心结、考试提升或赚钱，不把AI建议记成用户已完成的事实。
- 提供合成检索例子与至少一个不适用情境。运行 `npm test`，并实际查看资料筛选和正文。

开发者核验不能替代专业内容审阅。目前还没有覆盖全部年龄、疾病、地区和长期效果。发现来源变动或卡片不妥，应提交修正，不能悄悄删除旧ID。
